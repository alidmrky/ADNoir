# Sözleşme kuralları

Kök ve Shared kuralları geçerlidir. Proje/paket bağımlılığı ekleme; saf BCL kalır.
Servisler arası event/proto, response ve izin/mesaj katalogları burada bulunur.
Servise özel HTTP DTO burada bulunmaz. Entity taşınmaz. Proto alan numaralarını yeniden
kullanma; mevcut alan anlamını sessizce değiştirme. Yeni mesaj kodunda bütün kültürleri güncelle.
